# Changesets

Use Changesets to track version bumps and release notes per package.

Quick start:

1. Create a changeset after package changes:
   - `pnpm changeset`
2. Review pending releases:
   - `pnpm run release:status`
3. Apply version bumps:
   - `pnpm run release:version`
4. Publish changed packages:
   - `pnpm run release:publish`

See `docs/release-checklist.md` for the full release process.
